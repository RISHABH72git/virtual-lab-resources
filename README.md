# virtual-lab-resources (Open Virtual Labs & Simulations)
A curated collection of free virtual labs, simulations, and interactive tools for science, math, and social science education. Sourced from the [CSI Library OER guide](https://library.csi.cuny.edu/oer/virtuallabs-simulations).

> **Note:** Not all resources listed are strictly OER — some may be free but not openly licensed.

## 🏗️ Engineering & Environmental Science

### General Engineering

| Name | Description |
|------|-------------|
| [Data Nuggets](http://datanuggets.org/) | Free classroom activities co-designed by scientists and teachers to bring contemporary research and authentic data into the classroom |
| [Open Simulation Interface](https://opensimulationinterface.github.io/osi-documentation/) | Generic interface for environmental perception of automated driving functions in virtual scenarios |
| [SimSE](https://www.ics.uci.edu/~emilyo/SimSE/index.html) | A fully graphical and interactive software engineering simulation environment |
| [Verilator](https://www.veripool.org/wiki/verilator) | Converts Verilog/SystemVerilog designs into a C++ or SystemC model — functions as a compiler, not traditional simulator |
| [Flowsquare](http://flowsquare.com/#intro) | Two-dimensional computational fluid dynamics (CFD) software for unsteady, non-reactive/reactive flows |
| [GNU Radio](https://www.gnuradio.org/) | Software development toolkit that provides signal processing blocks to implement software radios |
| [SciLab](https://www.scilab.org/software/scilab) | Free and open source software for numerical computation for engineering and scientific applications |
| [LogicSim](http://www.tetzl.de/java_logic_simulator.html) | Design and simulate digital logic circuits with logic gates (AND, OR, FlipFlop, etc.) |
| [Virtual Labs (IIT Bombay)](https://www.vlab.co.in/participating-institute-iit-bombay) | Models physical phenomena and carries out simulations |
| [Reactor Lab](https://reactorlab.net/web-labs/) | Interactive chemical reactor simulations for chemical reaction engineering students |

### Climate

| Name | Description |
|------|-------------|
| [Energy3D](http://energy.concord.org/energy3d/) | Simulation-based engineering tool for designing green buildings and power stations using renewable energy |
| [ClimateSim](https://www.sciencebysimulation.com/climatesim/Simulator.aspx) | Climate-change simulation app; model GHG emission scenarios and simulate the Earth system's first-order response |
| [The Habitable Planet](https://www.learner.org/series/the-habitable-planet-a-systems-approach-to-environmental-science/) | Video course for high school teachers and college-level instruction, includes interactive labs |
| [HTML5 Simulations – Climate](https://physics.bu.edu/~duffy/HTML5/index.html) | Experiment with climate change scenarios |
| [American Museum of Natural History Teaching Modules](https://ncep.amnh.org/) | Open access modules with practical exercises in biodiversity conservation (some available in multiple languages) |
